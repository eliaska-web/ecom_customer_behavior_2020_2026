# Страница 2 «Customers» — спецификации CH-06…CH-10

Общая часть — см. `chart_specs.md`.

## CH-06 Клиенты по RFM-сегментам
- **Вопрос:** как распределена база по сегментам?
- **Тип:** bar (количество клиентов); grain = `Segment`; источник `mart_customers`.
- **Вывод:** 7 663 клиента с заказами; 337 без заказов в окне (отдельная плашка-пояснение).

## CH-07 Recency сегмента At Risk
- **Вопрос:** кого реактивировать в первую очередь?
- **Тип:** bar по `Recency Bucket` (0-90 / 91-180 / 181-365 / 365+); фильтр `Segment = 'At Risk'`; источник `mart_customers`.
- **Действие:** bucket 91-180 — первый приоритет кампании («ещё тёплые»), 365+ — win-back с большим дисконтом.

## CH-08 Churn Rate по membership_tier
- **Вопрос:** где отток концентрируется по уровням лояльности?
- **Тип:** bar; мера = `Churn Rate, %`; grain = `membership_tier`; источник `mart_customers`.
- **Действие:** tier с максимумом → аудит преимуществ программы лояльности.

## CH-09 Топ-10 стран по клиентам и выручке
- **Тип:** horizontal bar, две вкладки: клиенты (`COUNTD(customer_id)`) / `Revenue Delivered`; grain = `country`.
- **Источник:** `mart_customers` ⋈ `mart_orders` (для вкладки выручки).
- **Действие:** локализация промо на топ-рынки.

## CH-10 Распределение возраста
- **Тип:** histogram (bin = 5 лет); grain = клиент; источник `mart_customers`.
- **Вывод (подтверждено):** пик ~35 лет, диапазон 18-75, аномалий нет.
- **Действие:** таргетинг креативов на модальные когорты.
