## 1. Паспорт дашборда

| Параметр | Значение |
|---|---|
| Аудитория | Куратор/стейкхолдеры: маркетинг, CRM, категорийный менеджмент |
| Решения | Распределение маркетингового бюджета; реактивация At Risk; ревизия ассортимента; мониторинг оттока |
| Источник истины | `mart_orders` (все расчёты за окно); базы агрегатов указаны в каждом чарте |
| Фильтры (глобальные селекторы) | Период (`ym` / `order_date`), `category`, `country`, `Segment`, `order_status` |
| Drill-down | категория → товар; сегмент → список клиентов (выгрузка) |
| Freshness | Дата обновления витрин (ручная перезагрузка CSV) + `max(order_date)` в шапке |
| Data-quality индикатор | Баннер: «Выручка по умолчанию = Delivered; продуктовые метрики = все заказы кроме Cancelled; поля `return_rate` и `new_customers` исходной monthly_revenue не используются» |
| Владелец | Быкова Алина |

### Пороги и действия

| Индикатор | Порог | Действие |
|---|---|---|
| Доля At Risk в выручке | ≥ 25% | Запуск реактивационной кампании |
| Churn Rate | > 10% | Разбор причин оттока |
| Доля группы A в выручке | < 75% или > 85% | Ревизия ассортимента |
| return_rate категории | > 12% | Проверка качества категории |

## 2. Вычисляемые поля (формулы DataLens)

    Churn Rate, %     = COUNTD(IF([churned] = 1, [customer_id], NULL)) * 100.0 / COUNTD([customer_id])
    Revenue Delivered = SUM(IF([is_delivered] = 1, [total_amount_usd], 0))
    AOV Delivered     = SUM(IF([is_delivered] = 1, [total_amount_usd], 0)) / COUNTD(IF([is_delivered] = 1, [order_id], NULL))
    Return Rate, %    = SUM([returned]) * 100.0 / COUNTD([order_id])
    Revenue Share, %  = SUM([revenue_usd]) * 100.0 / TOTAL(SUM([revenue_usd]))
    Recency Bucket    = CASE WHEN [recency] <= 90 THEN '0-90'
                         WHEN [recency] <= 180 THEN '91-180'
                         WHEN [recency] <= 365 THEN '181-365'
                         ELSE '365+' END

## 4. Правила оформления (обязательны для всех чартов)

1. Заголовок = вопрос или вывод, не имя поля; в заголовке — база агрегата и период.
2. Подписи осей с единицами (USD, клиенты, %); легенда только при необходимости.
3. Запрещены: 3D, двойная ось без обоснования, pie для сравнения > 3 категорий, обрезанная шкала без предупреждения.
4. Под каждым чартом — строка «Вывод» (1 предложение) и «Действие» (порог из паспорта).
5. Все меры с базой «Delivered» или «кроме Cancelled» помечены явно; иных баз в дашборде нет.
6. Идентификаторы чартов (CH-01…CH-19) используются в спецификациях страниц и в чек-листе сверки с витринами.
