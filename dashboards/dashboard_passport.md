# Паспорт дашборда: E-Commerce Customer Behavior & Sales (2020–2026)

## Название
E-Commerce Customer Behavior & Sales (2020–2026).
Публичная ссылка: https://datalens.yandex/gia0wfc25ex2z

## Назначение
Оперативный мониторинг продаж, клиентской базы и товарного портфеля интернет-магазина за 2020-01…2026-03.
Поддерживает решения: распределение маркетингового бюджета; реактивация At Risk; ревизия ассортимента; мониторинг оттока и возвратов.

## Владелец
Быкова Алина, Data Analyst.

## Пользователи
Куратор; маркетинг; CRM; категорийный менеджмент. Просмотр — по публичной ссылке.

## Источник данных
Четыре CSV-витрины в `data/marts/`, построены `notebooks/05_bi_marts.ipynb` из `data/processed/`:
- `mart_customers.csv` — 8 000 клиентов;
- `mart_orders.csv` — 25 000 заказов (денормализован: содержит `country`, `membership_tier`, `Segment`, `churned`);
- `mart_products.csv` — 140 товаров;
- `mart_monthly.csv` — 75 месяцев.

Первоисточник: Kaggle, CC BY-SA 4.0, данные синтетические. Срез данных: 2026-03-30.

## Датасеты
| Датасет | Источник | Особенность |
|---|---|---|
| ds_customers | mart_customers.csv | клиентские метрики, снимок на 2026-03-30 |
| ds_orders | mart_orders.csv | факты заказов; клиентские атрибуты денормализованы |
| ds_products | mart_products.csv | база «все заказы кроме Cancelled» |
| ds_monthly | mart_monthly.csv | месячные агрегаты Delivered-базы |

Каждый датасет = один источник; JOIN между датасетами не используются (осознанное решение).

## Grain
- mart_orders: одна строка = один заказ (`order_id` уникален).
- mart_customers: одна строка = один клиент (`customer_id` уникален).
- mart_products: одна строка = один товар (ключ `category` + `product_name`).
- mart_monthly: одна строка = один месяц (`ym`).

## KPI
| KPI | Датасет | Формула |
|---|---|---|
| Выручка (Delivered) | ds_orders | SUM(IF([is_delivered] = 1, [total_amount_usd], 0)) |
| Заказы | ds_orders | COUNTD([order_id]) |
| AOV (Delivered) | ds_orders | SUM(IF([is_delivered]=1,[total_amount_usd],0)) / COUNTD(IF([is_delivered]=1,[order_id],NULL)) |
| Уникальные клиенты с заказами | ds_orders | COUNTD([customer_id]) |
| Churn Rate, % | ds_customers | COUNTD(IF([churned]=1,[customer_id],NULL)) * 100.0 / COUNTD([customer_id]) |
| Return Rate, % | ds_orders | SUM([returned]) * 100.0 / COUNTD([order_id]) |

## Селекторы
| Селектор | Поле | Примечание |
|---|---|---|
| Год | ds_orders.year / ds_monthly.year | продуктовые и клиентские чарты не реагируют (см. Ограничения) |
| Категория | category | влияет на заказы и продуктовые чарты |
| Страна | country | влияет на заказы и клиентские чарты |
| Сегмент | Segment | влияет на заказы и клиентские чарты |
| Статус заказа | order_status | только чарты на ds_orders |

## Частота обновления
Ручная: перезапуск `05_bi_marts.ipynb` → замена CSV в подключениях DataLens → «Обновить поля» в датасетах.
Свежесть отображается в баннере дашборда через `data_snapshot_date`.

## Ограничения
- Данные синтетические; выводы иллюстративные.
- Базы агрегатов: Delivered (20 497 заказов) vs «кроме Cancelled» (23 544) — прямое сравнение запрещено, базы указаны в заголовках чартов.
- XYZ-матрица вырождена: 100 % товаров в Z (медиана CV 0,93); решения по ассортименту — только через ABC.
- `customer_rating`: оценки только у ~45 % Delivered-заказов; импутации нет; чарты рейтинга сопровождаются оговоркой.
- `new_customers_calc` = первый заказ в окне 2020-01…2026-03; у 191 клиента, зарегистрированного до 2020, история до окна недоступна.
- 337 клиентов без заказов в окне помечены сегментом «No orders in window».
- Клиентские метрики — снимок на 2026-03-30; селектор периода на них не влияет.
- Отклонения визуализаций: CH-18 — две смежные колонки вместо стека; CH-19 — сводная таблица с заливкой вместо heatmap; топ-10 в CH-09 зафиксирован по срезу.

## Известные риски
- Селектор `order_status = Cancelled` обнуляет Delivered-KPI — ожидаемое поведение фильтра, может быть неверно истолковано пользователем.
- Файловые подключения DataLens хранят копию CSV: после обновления витрин требуется ручная замена файла и «Обновить поля».
- Селекторы не всегда связывают чарты разных датасетов автоматически; при отсутствии связи используются парные селекторы.

Пороговые правила:
| Индикатор | Порог | Действие |
|---|---|---|
| Доля At Risk в выручке | ≥ 25 % | запуск реактивационной кампании |
| Churn Rate | > 10 % | разбор причин оттока |
| Доля группы A | < 75 % или > 85 % | ревизия ассортимента |
| Return rate категории | > 12 % | проверка качества категории |
