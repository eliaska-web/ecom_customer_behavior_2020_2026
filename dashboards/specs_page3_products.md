# Страница 3 «Products» — спецификации CH-11…CH-15

Общая часть — см. `chart_specs.md`.

## CH-11 Выручка по ABC-группам
- **Тип:** bar с подписями долей; grain = `ABC_Group`; источник `mart_products`.
- **Ожидаемый вывод:** A = 79,7% выручки (62 товара).
- **Действие:** доля A вне коридора 75-85% → ревизия ассортимента (порог паспорта).

## CH-12 Топ-20 товаров (таблица)
- **Колонки:** product_name, category, ABC_Group, XYZ_Group, revenue_usd, orders_cnt, return_rate_pct, avg_rating.
- **Источник/grain:** `mart_products`; grain = товар; в заголовке база: «все заказы кроме Cancelled».
- **Действие:** сортировка по return_rate_pct desc → кандидаты на проверку качества.

## CH-13 Рейтинг против выручки
- **Вопрос:** влияет ли качество (rating) на выручку?
- **Тип:** scatter: X = `avg_rating`, Y = `revenue_usd`, size = `orders_cnt`, color = `ABC_Group`; источник `mart_products`.
- **Искажения:** `avg_rating` считается только по заказам с оценкой (`has_rating = 1`) — указать в подписи.
- **Вывод:** ассоциация, не причинность — формулировка осторожная.

## CH-14 Return Rate по категориям
- **Тип:** horizontal bar; мера = `Return Rate, %` (из `mart_orders.returned`); grain = `category`.
- **Действие:** > 12% → разбор причин возвратов категории (порог паспорта).

## CH-15 Распределение CV (стабильность спроса)
- **Тип:** histogram `cv` из `mart_products` с вертикальными линиями порогов 0,10 и 0,25.
- **Ожидаемый вывод (подтверждено):** min 0,46, медиана 0,93 → 100% товаров в Z; матрица XYZ вырождена.
- **Действие:** XYZ по SKU не использовать для запасов; решения — по ABC.
